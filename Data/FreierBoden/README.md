# Free terrain: terrain textures from CC0 scans

241 terrain textures (`Art/Terrain/<name>.dds`, BC7, HD, no mip levels) as a freely licensed replacement for EA's
`art/terrain/*.tga` (all of them, covering every map cell of all 170 maps of both games). Sources: Poly Haven and
ambientCG, all **CC0 1.0**; authors and addresses are listed in [ASSET_CREDITS.md](../../ASSET_CREDITS.md). Generated by
`tools/assets/boden_frei.py` from the project's own fixed values (tones, spread, speckles); no EA file is read while
generating. The file names are the interface to `Terrain.ini`.

Parking lots (lines in their own geometry, line image from ambientCG `RoadLines003`), fields (computed rows of plants)
and toxic patches (own colours) are included. Not replaced are the twelve `Terrain.ini` entries without a TGA and the
road textures (`art/textures/tr*.dds`, which are not terrain tiles; see `Data/FreieStrassen`).

Loading: the engine reads `<name>.dds` instead of the TGA, from any source of the file system. By default the game loads
the package from `ProjectData\Inhalt\FreierBoden` (the build copies it there); `-freeContent ea` switches it off. `-mod`
takes this folder with its loose files, a ZIP archive with the same content (`Art/Terrain/...` inside, stored or
deflated) or a BIG archive:

    GZHNeoZH.exe -mod <repo>\Data\FreierBoden
    GZHNeoZH.exe -mod <path>\FreierBoden.zip
    python tools/assets/boden_frei.py archiv --ziel <path>/BodenFrei.big
    GZHNeoZH.exe -mod <path>/BodenFrei.big

Relative paths given to `-mod` are relative to the user folder. Loose files of a mod folder take precedence over its
archives. One tier (HD) serves SD, HD and UHD.

Relief: for every texture there is `Art/Terrain/<name>_n.dds` (BC7, HD) with normals (R, G), gloss (B) and the strength
of the baked-in light (A), generated by `boden_frei.py relief` from the same scans and masks as the colour. The engine
reads them only with `-d3d11Effects terrainnormal` (detail level *Very high*); without these files nothing changes.
Recompute them only after the colour textures (the tool measures the baked-in light on the colour file next to it).

The DDS files have been sharpened once (unsharp mask, strength 0.5, four bands, falloff 0.75; `boden_frei.py
schaerfen`) and then re-encoded as BC7. Do not sharpen them a second time: a fresh build from the PNGs (`boden_frei.py
bauen`) gives the unsharpened version.
