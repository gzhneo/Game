# Free roads: road textures from CC0 scans

63 road textures (`Art/Textures/<name>.dds`, BC7, full mip chain) as a freely licensed replacement for EA's
`art/textures/tr*.dds`: every texture that `Roads.ini` of either game refers to (roads, paths, tracks, markings, decals;
bridges are models and not affected), plus the manhole cover `trstrtholecvr.dds`, which `Roads.ini` names but EA's data
lacks. Sources: 24 scans from Poly Haven and ambientCG, all **CC0 1.0**; authors and addresses are listed in
[ASSET_CREDITS.md](../../ASSET_CREDITS.md) (section "Free road textures"). Generated by `tools/assets/strassen_frei.py` (paths:
`tools/assets/strassen_wege.py`) from the project's own fixed values (tones, widths, markings, edges, its own stroke
font); no EA file is read while generating. The only interface to EA's data are the file names, the road widths from
`Roads.ini` and the layout of the fields within a texture (straight road, curves, crossings, ends; `W3DRoadBuffer.cpp`).

The files are stored at UHD size (four times EA's edge length); `texturpaket.txt` gives EA's size per texture. The game
picks the matching mip level for each texture tier: SD at EA's size, HD at twice, UHD at four times the edge length.

Loading: used by default as free content. The build copies the package to `ProjectData\Inhalt\FreieStrassen` next to the
program; `-freeContent ea` switches it off. It still works as a mod (then without the mip offset, at file size):

    GZHNeoZH.exe -mod <repo>\Data\FreieStrassen

Rebuilding (UHD, `--stufe 4`, the default; about 40 minutes with six processes), then write `texturpaket.txt`:

    python tools/assets/strassen_frei.py bauen --ziel Data/FreieStrassen/Art/Textures --prozesse 6
    python tools/assets/strassen_frei.py manifest
    python tools/assets/strassen_frei.py pruefen

`--stufe 1` produces EA's size, `--stufe 2` HD (set `manifest --stufe` to match).
